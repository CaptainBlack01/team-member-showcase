# Northwind Studio — Team Member Showcase

An editorial-style team showcase built with pure HTML, CSS, and JavaScript.

## Features

- Responsive card grid with CSS-generated gradient avatars and initials
- Department filters (All, Design, Engineering, Product)
- Hover lift effect and animated card entrance
- Social links with accessible labels
- Keyboard-accessible filters and empty state
- No external images required

## Run

Open `index.html` in a modern browser.
